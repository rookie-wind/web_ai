使用说明

  • 自动检测：服务器自动检测你的 IP 并分配 Token，无需手动输入
  • 权限分级：localhost → 系统级（读写），其它 IP → 用户级（只读）
  • Skills 包：服务器自动打包 .trae/skills/ 目录，无需手动压缩
  • 分发：点击「复制到剪贴板」或「下载 .md」，将文本发送给其他用户
  • 接入：接收者将整段文本粘贴给 AI Agent（如 Trae），Agent 自动完成：写入 mcp.json → 安装 Skills → 调用 list_mcp_tools 验证
  • 安全：Token 是临时凭证，请勿提交仓库、贴到群聊或写入日志
