使用说明

  • 自动检测：服务器自动检测你的 IP 并分配 Token，无需手动输入
  • 权限分级：本机 IP（含 localhost 和网卡 IP）→ 系统级（读写），其它 IP → 用户级（只读）
  • Token 按 IP 固定：非本机 Token 与你的访问 IP 绑定，服务器重启后仍可继续使用，无需重新获取
  • IP 变化需重新获取：如果你的 IP 发生变化（DHCP、更换网络等），请重新打开本页面获取新 Token
  • Agent 资源包：服务器自动打包 .trae/skills/ 目录，包含 Skill 文档、Agent 配置、工具、模板、校验器、参考资料和 manifest
  • 分发：向其他用户分享本接入页地址，由其独立获取 Token；复制与下载的配置仅供当前用户使用
  • 接入：将整段文本粘贴给所选平台的 AI Agent，完成：写入平台 MCP 配置 → 安装资源包 → 校验 manifest → 调用 list_mcp_tools 验证
  • 安全：Token 是临时凭证，请勿提交仓库、贴到群聊或写入日志；每个 IP 需独立打开本页面获取自己的 Token
