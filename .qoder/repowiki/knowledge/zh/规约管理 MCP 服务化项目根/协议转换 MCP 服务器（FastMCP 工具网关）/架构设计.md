单文件 ASGI 应用 `server.py` 以 `mcp.server.fastmcp.FastMCP` 为核心，通过自定义 `CompositeApp` 实现路由分发：`/`、`/access` 返回静态 `static/access.html`；`/api/access-info` 返回自动检测的 baseUrl、Token、权限级别与服务器 IP；`/api/docs/export-skills-package` 与 `/api/docs/export-skills` 动态打包 `.trae/skills/` 目录并返回 ZIP/Markdown；其余路径统一经 `AuthMiddleware` 校验 `Authorization: Bearer <TOKEN>` 后转发给 FastMCP 的 MCP 端点。鉴权由 `TokenManager` 管理：localhost（127.0.0.1/::1/localhost 及本机 LAN IP）使用环境变量 `MCP_AUTH_TOKEN` 作为管理员 Token 授予 system 级读写权限，非 localhost 客户端通过 `secrets.token_hex(16)` 在内存中分配 user 级只读 Token，并通过 `contextvars` 将 `access_level`、`source` 注入到各 `@mcp.tool()` 处理器中。依赖方向单向：启动入口 → CompositeApp → AuthMiddleware → FastMCP 工具 → `api_client.ProtocolApiClient`（httpx 异步调用规约管理后端）。`mcp_client.py` 仅作为兼容壳，实际客户端逻辑位于随资源包分发的 `.trae/skills/pca/tools/mcp_client.py`。
