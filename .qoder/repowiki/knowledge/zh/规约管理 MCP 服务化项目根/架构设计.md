根目录由三个协作层构成：mcp_server（FastMCP ASGI 服务）作为协议转换网关，server.py 用 @mcp.tool() 把后端 POST 接口逐一封装为 MCP 工具，api_client.py 统一封装 httpx.AsyncClient 请求并收敛网络/鉴权/HTTP 错误；.trae/mcp.json 作为 IDE 客户端连接入口，install.bat/start.bat 完成虚拟环境初始化、Token 注入与服务启动，形成「安装→启动→IDE 自动连接」的一体化链路；规约管理MCP服务化Spec.md 与规约管理基础数据模块Spec.md 共同定义 47 个 MCP 工具与 30 个后端 API 的双向映射矩阵，新增工具必须同步更新 Spec 中的工具清单与 API 映射，确保协议契约在前后端一致。
