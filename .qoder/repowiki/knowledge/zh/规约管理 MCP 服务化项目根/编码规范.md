- 每个后端 API 对应一个独立的 async def MCP 工具函数，参数校验在 server.py 中完成后再委托给 api_client.py 的 httpx 请求
- 所有后端接口统一使用 POST 方法，请求头携带自定义 Token 字段，响应体遵循 { code: number, data: object, message: string } 约定，code==20000 表示成功
- 错误处理统一在 api_client._request 中收敛，按 NETWORK_ERROR / API_ERROR / AUTH_ERROR / HTTP_ERROR 分类返回结构化错误对象
- 新增工具需同步更新 openspec 工件中的工具清单与 API 映射，保持 Spec 与实现一致
