## 1. 采用的方式
本项目采用最轻量的 Python 运行时配置方案：通过 `os.getenv` 读取环境变量，配合 `.env` 文件提供默认值；没有引入 pydantic-settings、python-dotenv、configparser 等第三方配置库。启动脚本 `start.bat` 在 Windows 环境下将 `.env` 中的键值对解析为进程环境变量后再执行 `server.py`。

## 2. 关键文件
- `mcp_server/server.py`：唯一承载配置加载逻辑的文件（第 39–48 行）
- `mcp_server/.env`：存放敏感配置（如 `MCP_AUTH_TOKEN`）
- `mcp_server/start.bat`：Windows 启动脚本，负责从 `.env` 注入环境变量
- `openspec/config.yaml`：OpenSpec 工具的配置（与 MCP 服务运行无关，仅描述变更工件规范）

## 3. 架构与约定
### 3.1 配置项清单
| 变量名 | 类型 | 默认值 | 用途 |
|---|---:|---|---|
| `MCP_HOST` | 字符串 | `0.0.0.0` | Uvicorn/FastMCP 监听地址 |
| `MCP_PORT` | 整数 | `8765` | 监听端口 |
| `MCP_AUTH_TOKEN` | 字符串 | `""` | 管理员 Bearer Token（localhost 系统级权限） |

所有配置在模块顶层以常量形式暴露（`HOST`/`PORT`/`AUTH_TOKEN`），随后被 `FastMCP(..., host=HOST, port=PORT)` 和 `TokenManager(admin_token=AUTH_TOKEN)` 消费。

### 3.2 路径与资源定位
- `SCRIPT_DIR = Path(__file__).parent.resolve()`：当前文件所在目录
- `PROJECT_ROOT = SCRIPT_DIR.parent`：仓库根目录
- `SKILLS_DIR = PROJECT_ROOT / ".trae" / "skills"`：Skills 包源目录
- `HTML_PATH = SCRIPT_DIR / "static" / "access.html"`：接入页面模板
这些路径全部基于相对位置计算，不依赖工作目录。

### 3.3 权限模型作为“运行时配置”的一部分
`TokenManager` 根据访问来源 IP 决定权限级别：
- `LOCALHOST_IPS = {"127.0.0.1", "::1", "localhost"}` → `system`（读写）
- 其他 IP → `user`（只读），并自动用 `secrets.token_hex(16)` 生成 `metam_pat_...` 前缀的 Token
该策略由代码硬编码，未暴露为可配置开关。

### 3.4 启动流程中的配置装配
```text
.env (mcp_server/.env)
  ↓ start.bat 解析为进程环境变量
  ↓ os.getenv("MCP_*") 读取
  ↓ FastMCP(host, port) + TokenManager(admin_token)
  ↓ uvicorn.run(wrapped_app, host, port)
```
`start.bat` 中若检测到 `MCP_AUTH_TOKEN` 为空会直接中止启动并提示先运行 `install.bat` 或手动设置。

## 4. 约定与约束
- **配置来源优先级**：进程环境变量 > `.env` 文件（由 `start.bat` 覆盖式 `set` 注入）> 代码内 `os.getenv(key, default)` 默认值。
- **敏感信息隔离**：`MCP_AUTH_TOKEN` 必须放在 `.env` 中，不在代码中硬编码；生产环境应通过容器/平台环境变量注入。
- **最小化原则**：除 `MCP_HOST`/`MCP_PORT`/`MCP_AUTH_TOKEN` 外无其他外部配置项；IP 白名单、写操作集合 `WRITE_TOOLS`、跳过目录 `SKIP_DIRS` 等均硬编码在 `server.py` 中。
- **OpenSpec 配置独立**：`openspec/config.yaml` 仅用于 OpenSpec 变更管理工具，声明 `schema: spec-driven`，不参与 MCP 服务运行时配置。
- **无配置文件热重载**：所有配置在模块导入时一次性读取，修改后需重启服务。
- **缺失处理**：`ACCESS_HTML` 读取失败时回退为错误 HTML；`AUTH_TOKEN` 为空时打印警告并允许所有 IP 使用自动生成的 Token（降级模式）。
