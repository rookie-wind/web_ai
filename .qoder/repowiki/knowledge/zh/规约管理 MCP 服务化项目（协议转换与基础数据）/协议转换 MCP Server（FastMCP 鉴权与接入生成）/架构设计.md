单文件 ASGI 应用 `server.py` 以 `mcp.server.fastmcp.FastMCP` 为框架核心，通过自定义 `CompositeApp` 实现路由分发：`/`、`/access` 返回静态 `static/access.html` 接入页；`/api/access-info` 返回自动检测的 baseUrl、Token、权限级别与服务器 IP；`/api/docs/export-skills-package` 与 `/api/docs/export-skills` 动态打包 `.trae/skills/` 目录并返回 ZIP/Markdown；其余路径统一走 `AuthMiddleware` 校验 `Authorization: Bearer <TOKEN>` 后转发给 FastMCP 的 MCP 端点。鉴权由 `TokenManager` 管理：localhost（127.0.0.1/::1/localhost）使用环境变量 `MCP_AUTH_TOKEN` 作为管理员 Token 授予 system 级读写权限，非 localhost 客户端通过 `secrets.token_hex(16)` 在内存中分配 user 级只读 Token，并通过 `contextvars` 将 `access_level`、`source` 注入到各 `@mcp.tool()` 处理器中。工具清单集中声明于 `TOOL_DEFINITIONS`，其中仅 `list_mcp_tools` 完整实现，其余 6 个通过 `_stub_response` 占位并以 `_check_write_permission` 守卫写入类工具。依赖方向单向：启动入口 → CompositeApp → AuthMiddleware → FastMCP 工具；外部依赖仅为 `mcp` 与 `uvicorn`。
