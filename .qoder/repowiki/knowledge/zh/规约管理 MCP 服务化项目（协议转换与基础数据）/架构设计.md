根目录由两个子模块协作构成完整交付：mcp_server 子模块实现 MCP 协议服务器（server.py + api_client.py），通过 ASGI 中间件完成 Bearer Token 鉴权与 IP 分级权限，并将规约管理后端的 30+ 个 POST 接口逐一封装为 MCP 工具；openspec 子模块以 proposal/design/tasks/spec 工件描述并跟踪这些工具的增强变更。两者通过统一的 MCP 协议契约耦合——Skill 调用 MCP 工具 → server.py 路由到对应函数 → api_client.py 以 httpx.AsyncClient 发起带 Token 头的请求 → 后端返回统一 {code,data,message} 响应。部署层面，install.bat 在 .trae/ 下生成 mcp.json 客户端配置并写入 .env Token，start.bat 激活 .venv 并启动 server.py 监听 8765 端口，形成「安装→启动→IDE 自动连接」的一体化工作流。
