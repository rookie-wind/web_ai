# web-chat-ui Specification（delta）

## ADDED Requirements

### Requirement: 图在窄屏必须阈值混合适配

mermaid 图形渲染后，渲染层 MUST 按 SVG 自然宽度做阈值混合适配：自然宽不
超过适配阈值（默认约 700px，常量可调）的图形 MUST 清除内联宽度限制并缩放
适配气泡宽度（用户无需任何操作即可看全整图）；超过阈值的图形 MUST 保持
横向滚动且 MUST 提供可发现性提示（如边缘渐隐与"左右滑动查看"提示条），
MUST NOT 出现无提示的静默裁切。阈值与提示形态 MUST 在移动端与桌面端一致
生效；缩放适配 MUST NOT 依赖用户手势。

#### Scenario: 中小图缩放适配看全

- **WHEN** 助手输出一张自然宽不超过阈值的 mermaid 图（如三节点流程图）
- **THEN** 图形整体缩放至气泡宽度内完整可见，无横向滚动、无两侧裁切

#### Scenario: 超宽图横滚且有提示

- **WHEN** 助手输出一张自然宽超过阈值的泳道式大图（如四泳道交互图）
- **THEN** 图形按自然宽呈现并可在容器内横向滑动，容器呈现可发现性提示
  （边缘渐隐或"左右滑动查看"提示条），页面级布局 MUST NOT 出现横向溢出

#### Scenario: 回放路径适配一致

- **WHEN** 用户刷新或断线重连后回放含图历史消息
- **THEN** 图形按同一阈值策略适配，与实时路径呈现一致

### Requirement: mermaid 图形文本必须完整呈现

mermaid 图形内文本 MUST 完整呈现且定位正确：节点标签 MUST 居中于节点框内
（多行标签逐行定位正确，MUST NOT 因属性被消毒剥除而漂出框外）；连线边标签
文字 MUST 可见（MUST NOT 因消毒剥除容器而静默消失）。消毒白名单 MUST 覆盖
mermaid 产出的 SVG 定位属性（如 `dy`/`dx`）与经消毒的 `foreignObject` 边
标签容器；`foreignObject` 内部 HTML MUST 经同一白名单递归消毒，图形渲染
严格安全模式与 CSP 防线 MUST NOT 因本要求放宽。

#### Scenario: 多行节点标签在框内

- **WHEN** 助手输出含多行中文节点标签的流程图
- **THEN** 各行标签逐行居中呈现于节点框内，文字不溢出框外

#### Scenario: 边标签文字可见

- **WHEN** 助手输出的流程图包含带文字的连线（如"Modbus RTU 主动上报"）
- **THEN** 边标签文字在连线位置完整可见，不以空占位替代

#### Scenario: 消毒防线不因白名单放宽而失效

- **WHEN** 图形 SVG 中出现脚本或事件处理器（无论位于 foreignObject 内外）
- **THEN** 消毒移除该类内容，页面不执行脚本、不发起外部请求

## MODIFIED Requirements

### Requirement: 输入区必须提示可选路由前缀且不得强制

前端输入区 MUST 以提示文案说明可选路由前缀：`/web` 强制网页检索、`/xlpa`
强制协议助手，并说明不带前缀时自动判断。提示 MUST 允许紧凑形态：输入框
失焦时占位提示 MAY 为单行短文案（含 `/web`/`/xlpa` 关键字与可选语义），
但输入框获得焦点时占位提示 MUST 展开为含各前缀完整释义与"不带前缀自动
判断"的完整说明。提示 MUST NOT 要求用户每次输入都携带前缀；前端 MUST NOT
把 `/` 当作必须的命令入口，MUST NOT 拦截或改写用户输入，MUST NOT 新增会
改变会话模式的开关。前缀的识别与剥离由 Agent 侧完成。移动端表单控件
≥16px 字号契约不受紧凑化影响。

#### Scenario: 用户直接输入不带前缀

- **WHEN** 用户在输入框输入普通任务且不带 `/web` 或 `/xlpa`
- **THEN** 消息按原样发送，由 Agent 自动判定路由

#### Scenario: 用户使用可选前缀

- **WHEN** 用户在输入框以 `/web` 或 `/xlpa` 开头输入任务
- **THEN** 前端原样发送该文本，不做拦截或改写；Agent 识别前缀并强制本次路由

#### Scenario: 输入提示不构成强制

- **WHEN** 用户查看输入区提示
- **THEN** 提示只说明前缀为可选项，不出现"必须使用前缀"的要求

#### Scenario: 失焦紧凑聚焦完整

- **WHEN** 用户未聚焦输入框时查看输入区
- **THEN** 占位提示为单行短文案；聚焦输入框后占位提示展开为含前缀完整释义
  与"不带前缀自动判断"的完整说明，失焦后恢复紧凑形态

#### Scenario: 紧凑化不破坏反缩放契约

- **WHEN** 用户在移动端聚焦输入框或模型选择
- **THEN** 表单控件字号仍不小于 16px，页面不被自动放大
