## ADDED Requirements

### Requirement: 会话必须绑定一个 Qoder 云账号且会话级固定

每个 Web 会话 MUST 在创建时绑定恰好一个 Qoder 云账号，来源为服务端默认账号或
用户自带 PAT；账号凭据 MUST 在客户端构建时绑定、运行期 MUST NOT 切换（更换账号
MUST 新建会话）。自带 PAT MUST 仅经环境变量注入子进程，MUST NOT 出现在进程命令行
或日志。会话创建时 MUST 校验所用 PAT 能成功取得该账号的模型清单，校验失败 MUST
拒绝创建并给出可辨识原因，MUST NOT 留下可对话但模型不可用的会话。默认账号不可用
（无服务端 PAT 且无本机登录态）时 MUST 提示用户需自带 PAT。该账号是独立于 MCP
接入凭据、门禁票据、会话票据的另一层凭据，MUST NOT 改变写门禁与审计归属。

#### Scenario: 默认账号建会话

- **WHEN** 用户新建会话选择默认账号且默认 PAT 有效
- **THEN** 会话绑定默认账号、完成初始化、可取得该账号模型清单

#### Scenario: 自带 PAT 建会话

- **WHEN** 用户新建会话填入有效自带 PAT
- **THEN** 会话绑定该 PAT（仅经环境变量注入），用该账号的模型清单初始化

#### Scenario: 自带 PAT 校验失败

- **WHEN** 用户填入无效或过期的自带 PAT
- **THEN** 创建请求被拒绝并给出可辨识原因，不产生可用会话

#### Scenario: 账号会话级固定

- **WHEN** 会话已绑定某 Qoder 云账号
- **THEN** 运行期不切换该账号凭据；更换账号须新建会话

#### Scenario: 默认账号不可用

- **WHEN** 既无服务端 PAT 也无本机登录态
- **THEN** 新建会话提示需自带 PAT，不允许选择默认账号

### Requirement: 模型清单必须按当前账号拉取且只列启用模型

会话可用模型清单 MUST 取自当前绑定账号的账号级模型目录（随该账号订阅变化），
MUST 仅包含启用（isEnabled）的模型；清单 MUST 携带展示名与成本信息（免费标记、
价格系数）供用户按成本权衡。默认预选模型 MUST 满足：默认账号沿用服务端配置默认
模型；自带账号预选其清单首个启用模型（服务端配置默认模型若在该清单内则优先）。

#### Scenario: 清单随账号变化

- **WHEN** 两个会话分别绑定不同 Qoder 云账号
- **THEN** 各自模型清单反映各自账号订阅，互不混用

#### Scenario: 只列启用模型

- **WHEN** 账号模型目录中含有未启用模型
- **THEN** 会话可用清单仅呈现启用模型

#### Scenario: 自带账号默认预选

- **WHEN** 会话绑定自带账号且服务端配置默认模型不在其清单内
- **THEN** 预选该清单首个启用模型作为初值

### Requirement: 模型选择必须消息级生效且不切换凭据

用户 MUST 能在会话内按消息切换模型，切换 MUST 对下一条消息生效；模型切换 MUST
复用同一持久客户端，MUST NOT 切换 MCP 接入凭据或 Qoder 云账号，MUST NOT 重建
客户端或拉起新 CLI 进程。所选模型 MUST 属于当前账号的可用清单。

#### Scenario: 消息级切换

- **WHEN** 用户在会话中途改选另一启用模型并发送下一条消息
- **THEN** 该轮使用新模型，复用同一客户端与凭据，会话标识不变

#### Scenario: 切换不重建客户端

- **WHEN** 用户切换模型
- **THEN** 不出现新建 CLI 子进程或客户端重连行为

#### Scenario: 越清单拒绝

- **WHEN** 请求切换到一个不在当前账号清单内的模型
- **THEN** 切换被拒绝并给出提示

### Requirement: 自带 PAT 必须可记住可清除且默认仅内存

用户自带 PAT 默认 MUST 仅存于会话内存、会话结束即失；用户 MUST 可选"记住"将其
持久化到本 webchat 账号（per-user）供下次预填。记住的 PAT MUST 明文存于已
gitignore 的账号库（与既有明文 phone/code 同姿态），MUST NOT 进版本控制、MUST NOT
进日志或进程命令行，UI MUST 掩码显示。用户 MUST 能清除已记住的 PAT，清除后下次
MUST 重新输入。记住的 PAT 在建会话时 MUST 同样走有效性校验，失效 MUST 提示重新
输入。默认 MUST NOT 记住。

#### Scenario: 默认仅内存

- **WHEN** 用户自带 PAT 建会话且未选择记住
- **THEN** PAT 仅存于会话内存，会话结束或重启后不留存

#### Scenario: 记住并预填

- **WHEN** 用户选择记住自带 PAT
- **THEN** 该 PAT 明文存于本账号的 gitignore 账号库，下次新建会话预填（掩码显示）

#### Scenario: 清除已记住凭据

- **WHEN** 用户清除已记住的 PAT
- **THEN** 账号库不再含该 PAT，下次新建会话需重新输入

#### Scenario: 记住的凭据失效重校验

- **WHEN** 已记住的 PAT 失效后用户新建会话
- **THEN** 建会话校验失败并提示重新输入

#### Scenario: 凭据不进日志

- **WHEN** 检查服务日志与子进程命令行
- **THEN** 不出现 PAT 明文
