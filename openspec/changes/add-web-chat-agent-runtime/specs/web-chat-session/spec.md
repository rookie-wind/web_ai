## Purpose

定义 Web 对话会话的对外行为契约：准入与登录、会话与 agent 运行时及接入凭据的对应关系、
归属主体的稳定性、有序可重放的事件流、单写者与旁观语义、用户决策的回注方式，以及配额与
会话数据的保留期。

## ADDED Requirements

### Requirement: Web 会话必须经准入校验与业务登录后方可开始
系统 SHALL 要求用户在 Web 端先通过手机号+验证码完成准入校验与云端业务登录，未通过的
会话 MUST NOT 执行任何对话或工具调用。准入名单 MUST 独立于云端平台写权限配置存储。

#### Scenario: 未登录直接请求对话
- **WHEN** 客户端未携带有效会话凭据请求发起对话
- **THEN** 系统必须拒绝并只返回登录所需信息
- **THEN** 系统不得启动 agent 运行时

#### Scenario: 手机号未命中准入名单
- **WHEN** 登录手机号不在 web 准入名单内
- **THEN** 系统必须拒绝建立会话
- **THEN** 拒绝说明不得泄露名单内容或其他手机号是否在名单内

#### Scenario: 准入名单配置缺失
- **WHEN** web 准入名单文件缺失或无法解析
- **THEN** 系统必须拒绝所有 web 登录（fail-closed）
- **THEN** 系统不得因此回退为"允许所有手机号"

### Requirement: 用户会话与 agent 运行时及接入凭据必须一对一
系统 SHALL 为每个活跃 Web 会话分配独立的 agent 运行时实例和独立的 MCP 接入凭据，
MUST NOT 让多个用户会话共享同一实例或同一凭据。

#### Scenario: 两个用户同时对话
- **WHEN** 两个不同用户的会话同时处于活跃状态
- **THEN** 系统必须为每个会话使用各自独立的运行时实例与接入凭据
- **THEN** 一个会话的对话内容与工作区文件不得出现在另一个会话的输出中

#### Scenario: 共享凭据导致身份互相覆盖
- **WHEN** 系统检测到待建立的会话将复用另一活跃会话的接入凭据
- **THEN** 系统必须拒绝建立该会话并说明原因
- **THEN** 系统不得让后一个登录覆盖前一个会话的权限判定

#### Scenario: 运行时实例池已满
- **WHEN** 活跃会话数已达全局实例上限
- **THEN** 系统必须明确告知用户当前繁忙，并按配置排队或拒绝
- **THEN** 系统不得把新会话复用到他人正在使用的实例上

### Requirement: 刷新必须复用会话，多设备必须独立会话共享归属
系统 SHALL 在浏览器刷新后复用同一会话；同一用户在不同设备上的会话 SHALL 各自拥有独立
运行时实例与接入凭据，但业务归属 MUST 指向同一个稳定主体。

#### Scenario: 页面刷新
- **WHEN** 用户刷新页面或重新打开同一会话链接
- **THEN** 系统必须复用原会话与其接入凭据，不得新签一把凭据
- **THEN** 该会话已产生的产物与历史仍可继续访问

#### Scenario: 同一用户跨设备使用
- **WHEN** 同一手机号在 PC 与手机各开一个会话
- **THEN** 系统必须分配两个独立会话实例与两把接入凭据
- **THEN** 两个会话生成的模板、建档任务与操作日志必须归属同一个主体可互相回看

### Requirement: 业务归属必须与接入凭据解耦
系统 SHALL 以稳定用户引用派生 Web 路径的归属主体，MUST NOT 依赖接入凭据本身作为归属
键；接入凭据可轮换、可过期、可撤销，而归属主体在用户维度保持稳定。

#### Scenario: 接入凭据轮换后回看历史
- **WHEN** 某 Web 会话的接入凭据到期并被重新签发
- **THEN** 该用户此前生成的模板、上传的文件与阶段报告仍必须可回看
- **THEN** 该用户此前的操作日志仍必须在同一归属下可查询

#### Scenario: 接入凭据撤销不等于身份注销
- **WHEN** 系统撤销某个 Web 会话的接入凭据
- **THEN** 系统必须只停止该凭据的 MCP 接入能力
- **THEN** 系统不得因此删除或改判该用户归属下的业务产物

#### Scenario: IDE 接入路径保持现状
- **WHEN** 客户端通过 IDE 以 IP 分配的接入 Token 调用工具
- **THEN** 归属主体仍按既有规则由该接入 Token 派生
- **THEN** 本次变更不得改变 IDE 路径的归属结果

### Requirement: 对话必须以可重放的有序事件流交付
系统 SHALL 以自定义的有序事件契约向前端交付中间输出，事件必须携带单调序号并支持按游标
重放；事件内容 MUST 对凭据与口令脱敏。

#### Scenario: 移动设备断线后重连
- **WHEN** 客户端连接中断后带最后收到的序号重新连接
- **THEN** 系统必须补齐该序号之后的全部事件
- **THEN** 会话在后端的执行不得因连接中断而中止

#### Scenario: 前端遇到未知事件类型
- **WHEN** 事件流中出现前端未识别的事件类型
- **THEN** 前端必须降级展示该事件的原始内容而不得中断整个会话渲染

#### Scenario: 事件中携带凭据
- **WHEN** 工具入参或结果中包含 Token、口令、验证码
- **THEN** 交付给前端的事件必须为脱敏后的摘要，不得包含明文

### Requirement: 同一会话同时只允许一个执行者
系统 SHALL 为每个会话维护单一执行者持有权；其它打开同一会话的客户端 MUST 以只读方式
旁观，并可显式请求接管。

#### Scenario: 第二个窗口打开同一会话
- **WHEN** 同一会话在另一个标签页或设备被打开
- **THEN** 后打开者必须进入只读旁观状态并可看到完整事件流
- **THEN** 后打开者的输入框必须不可用并提示当前执行者

#### Scenario: 主动接管
- **WHEN** 旁观者请求接管会话
- **THEN** 系统必须中断原执行者正在进行的执行轮，再把持有权转移给接管者
- **THEN** 原执行者页面必须降级为旁观并收到被接管提示

#### Scenario: 持有者失联
- **WHEN** 持有者停止心跳或页面关闭超过持有时限
- **THEN** 系统必须自动释放持有权，使其它客户端可以开始输入

### Requirement: 用户决策必须区分补充说明与执行确认
系统 SHALL 把用户的补充说明作为普通对话内容回注同一会话上下文；写入类操作的确认
MUST NOT 通过对话文本表达，而必须经由服务端签发的一次性授权承载。

#### Scenario: 用户补充信息
- **WHEN** 在 agent 请求补充后用户提交新的说明文本
- **THEN** 系统必须将其作为该会话的下一条用户输入回注，保持上下文连续

#### Scenario: 用户确认执行计划
- **WHEN** 用户在计划卡片上点击确认
- **THEN** 后端必须针对该计划标识签发一次性授权，并在此后允许写入动作通过校验

#### Scenario: 用户取消执行计划
- **WHEN** 用户在计划卡片上点击取消
- **THEN** 系统必须不签发授权，并把拒绝结果告知 agent 以便继续对话
- **THEN** 系统不得把取消动作解释为部分执行

### Requirement: 会话用量必须受可配置配额约束
系统 SHALL 提供可配置的每用户用量上限、全局活跃实例上限与单轮最大工具迭代上限，并按
用户计量。

#### Scenario: 超出每日用量上限
- **WHEN** 某用户当日对话轮次达到上限
- **THEN** 系统必须拒绝新的对话请求并说明达到上限，且提示上限可由管理方调整

#### Scenario: 单轮工具迭代超限
- **WHEN** 一轮对话内的工具调用迭代次数达到上限
- **THEN** 系统必须中止该轮并向用户说明中止原因，不得静默返回部分结果

### Requirement: 会话事件流必须双写自有存储并按保留期清理
系统 SHALL 将事件流同时写入自有会话存储，并 SHALL 按保留期滚动清理；用户主动删除会话
时 MUST 立即物理删除。自有存储 MUST 是会话列表与历史回看的事实源。

#### Scenario: 保留期内回看历史会话
- **WHEN** 用户在会话列表中打开一个仍在保留期内的历史会话
- **THEN** 系统必须展示该会话的完整事件历史

#### Scenario: 超出保留期
- **WHEN** 会话事件超过配置的保留期
- **THEN** 系统必须清理对应事件内容
- **THEN** 系统不得因清理而同时删除写操作审计日志

#### Scenario: 用户主动删除会话
- **WHEN** 用户在会话列表中删除某个会话
- **THEN** 系统必须立即物理删除该会话的事件内容
