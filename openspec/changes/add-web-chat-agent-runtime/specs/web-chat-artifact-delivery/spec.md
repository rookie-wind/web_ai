## Purpose

定义 Web 会话中上传物与产物的存储归属、不同类别文件的落点分道规则、产物交付的下载方式，
以及按产物分类的保留期与清理时机；同时约束图片识别必须在服务端本地完成，不为识别引入第二
个外部数据目的地。

## ADDED Requirements

### Requirement: 上传物与产物必须按归属主体分区存储
系统 SHALL 将 Web 会话产生的上传文件与产物按稳定归属主体分区保存，并 MUST 拒绝跨归属
主体的访问；归属主体由用户身份派生，不随接入凭据轮换而变化。

#### Scenario: 列出自己的产物
- **WHEN** 用户请求产物列表
- **THEN** 系统必须只返回归属于当前用户的产物条目及其名称、大小与到期时间

#### Scenario: 访问他人产物
- **WHEN** 请求的产物标识不属于当前归属主体
- **THEN** 系统必须拒绝访问，不得返回该产物的任何内容或元数据

### Requirement: 建档数据与协议文档必须分道存放
系统 SHALL 把用于自动建档的已填表格交给服务端既有的建档存储通道处理，agent MUST 通过
工具读取其内容；系统 SHALL 把协议类文档与图片保存在会话工作区供 agent 直接读取。

#### Scenario: 上传已填建档表格
- **WHEN** 用户在页面上传已填写的建档表格
- **THEN** 系统必须经由服务端建档通道保存并返回文件标识，归属该用户
- **THEN** agent 必须通过工具读取该表格内容，而不是从工作区文件读取

#### Scenario: 上传协议文档
- **WHEN** 用户上传协议文档（文档或图片）
- **THEN** 系统必须将其识别或转换后的文本放入该会话工作区供 agent 读取

#### Scenario: 为统一体验而把建档表格放进工作区
- **WHEN** 实现上考虑把已填建档表格也复制进会话工作区
- **THEN** 系统必须保持"只有服务端工具触碰建档数据"的约束，不得复制入工作区

### Requirement: 产物下载必须通过服务端代理与一次性授权
系统 SHALL 通过后端代理提供产物下载，下载动作 MUST 使用请求头携带会话凭据与一次性授权；
下载链接与查询参数 MUST NOT 携带 Token、归属摘要或其它凭据信息。

#### Scenario: 正常下载产物
- **WHEN** 用户先申请下载授权，再以请求头携带凭据与授权取出内容
- **THEN** 系统必须校验归属与授权有效性后流式返回该产物

#### Scenario: 授权过期或被重复使用
- **WHEN** 使用已过期或已消费完毕的授权请求下载
- **THEN** 系统必须拒绝并说明授权失效，需重新申请

#### Scenario: 凭据出现在地址中
- **WHEN** 下载请求把凭据或归属摘要放在地址查询参数中
- **THEN** 系统必须拒绝该请求形态并指引使用请求头方式

#### Scenario: 既有以地址参数传递凭据的端点在公网被访问
- **WHEN** 公网部署形态下收到以地址查询参数传递凭据或归属摘要的既有端点请求
- **THEN** 系统必须拒绝该请求并返回明确原因，内网部署形态保持既有行为

### Requirement: 产物必须按分类保留期清理
系统 SHALL 为会话产物按分类适用可配置的保留期，并 SHALL 沿用既有产物分类语义：输入、
结果、审计、补偿、模板与可复用缓存必须保留至保留期结束，临时与敏感临时产物可提前删除；
未知分类 MUST 按保留处理。

#### Scenario: 会话销毁时的临时工作区
- **WHEN** 会话被销毁或空闲超时回收
- **THEN** 系统必须清除该会话工作区目录中的临时内容

#### Scenario: 含凭据的上传表格
- **WHEN** 建档任务进入终态且已超过含凭据文件的短保留期
- **THEN** 系统必须删除该上传表格本体
- **THEN** 系统必须保留其审计记录与阶段报告

#### Scenario: 一般产物与模板
- **WHEN** 产物生成后未超过其分类保留期
- **THEN** 系统必须允许该用户在保留期内重复下载

#### Scenario: 分类无法识别
- **WHEN** 某产物条目的分类不在已知分类内
- **THEN** 系统必须保留该条目而不得删除

### Requirement: 图片识别必须在服务端本地完成
系统 SHALL 在服务端本地完成上传图片的文本识别，MUST NOT 为识别环节引入外部识别服务；
识别结果 SHALL 以文本形式写入会话工作区供 agent 读取。

#### Scenario: 上传拍照的协议文档
- **WHEN** 用户上传照片形式的协议文档
- **THEN** 系统必须在本地识别并把结果文本写入会话工作区
- **THEN** 系统不得因识别而向第二个外部服务发送该图片

#### Scenario: 识别失败或质量不足
- **WHEN** 本地识别失败或结果明显不完整
- **THEN** 系统必须明确告知用户识别失败并建议使用文本粘贴或表格文件上传
- **THEN** 系统不得静默以空内容或猜测内容继续流程

#### Scenario: 结构化表格照片
- **WHEN** 上传的是包含行列关系的表格照片
- **THEN** 系统必须尽可能保留行列对应结构；无法保留时必须提示改用电子表格上传，
  不得让用户误以为结构已完整识别
