## Purpose

定义 Web 会话所使用的 agent 运行时的能力边界契约：显式工具白名单、文件访问范围、门禁
配置自身的不可篡改要求、写入类操作的服务端票据与 Fail-Closed 语义，以及会话凭据签发端
点的访问控制与可观测要求。

## ADDED Requirements

### Requirement: agent 运行时能力必须以显式白名单授予
系统 SHALL 以显式白名单确定每个会话中 agent 可用的能力集合，未列入白名单的能力 MUST
不可用。首期白名单 MUST NOT 包含命令执行能力。

#### Scenario: 模型请求执行命令
- **WHEN** agent 在首期会话中尝试调用命令执行能力
- **THEN** 系统必须拒绝该调用并产生一条拦截事件说明被拒原因
- **THEN** 系统不得以"用户已登录"为由放行

#### Scenario: 需要执行转换脚本或打包
- **WHEN** 协议转换流程需要执行校验、模拟转换或生成分发包
- **THEN** 系统必须通过服务端提供的工具完成，而不是通过 agent 本地执行能力完成

### Requirement: 文件读写必须限制在会话工作区与资源包母本
系统 SHALL 允许 agent 在当前会话工作区内读写文件，并 SHALL 允许其只读访问资源包母本；
对工作区与母本之外的任何读写 MUST 拒绝。

#### Scenario: 读取本会话上传的文档
- **WHEN** agent 读取当前会话工作区内由本用户上传的协议文档
- **THEN** 系统必须允许

#### Scenario: 写入工作区之外的路径
- **WHEN** agent 试图写入服务端代码目录、资源包源目录或凭据配置文件所在路径
- **THEN** 系统必须拒绝该写入并记录拦截事件
- **THEN** 系统不得因权限模式为自动放行而绕过该拒绝

#### Scenario: 读取凭据类文件
- **WHEN** agent 试图读取超级账号配置、Token 注册表、业务 Token 缓存或他人会话工作区
- **THEN** 系统必须拒绝该读取并记录拦截事件

#### Scenario: 资源包母本被请求修改
- **WHEN** agent 试图修改共享只读的资源包母本
- **THEN** 系统必须拒绝，母本对所有会话必须保持只读

### Requirement: 门禁配置不得位于 agent 可写范围
系统 SHALL 将 agent 的工具白名单、权限规则与拦截配置存放于会话工作区之外，并 SHALL 在
每次会话启动时由后端注入；agent 在工作区内产生的同类配置 MUST NOT 生效。

#### Scenario: 工作区内出现配置文件
- **WHEN** 会话工作区内出现由上传内容或模型输出产生的权限/拦截配置文件
- **THEN** 系统必须以注入配置为准，忽略工作区内的配置
- **THEN** 系统不得让 agent 通过改写工作区文件放宽自身权限

#### Scenario: 注入配置缺失或不可解析
- **WHEN** 后端未能提供有效的注入配置
- **THEN** 系统必须拒绝启动该会话的 agent 运行时并返回明确错误
- **THEN** 系统不得以"无限制"作为默认回退

### Requirement: 写入类工具的确认必须由服务端一次性授权承载
系统 SHALL 要求所有写入类工具的执行携带由服务端针对具体计划标识签发的一次性授权；
agent 或模型自行声明的确认参数 MUST NOT 被视为用户确认。

#### Scenario: 无授权的写入请求
- **WHEN** 写入类工具调用未附带有效一次性授权
- **THEN** 系统必须拒绝执行并要求先在页面完成确认

#### Scenario: 授权已使用或已过期
- **WHEN** 写入类工具调用附带了一个已消费或已过期的授权
- **THEN** 系统必须拒绝执行并说明授权失效

#### Scenario: 验证服务不可达
- **WHEN** 授权校验依赖的后端服务暂时不可达或校验过程异常
- **THEN** 系统必须拒绝执行（fail-closed），不得默认放行

#### Scenario: 只读工具不受该门禁约束
- **WHEN** 调用只读/探测类工具
- **THEN** 系统不得要求一次性授权，也不得因校验不可达而阻断只读查询

#### Scenario: 计划变化后旧授权不可复用
- **WHEN** 用户重新生成计划后，使用上一个计划标识的授权发起写入
- **THEN** 系统必须拒绝，并要求针对新计划重新确认

### Requirement: 会话凭据签发端点必须受独立服务凭据与来源控制保护
系统 SHALL 提供为 Web 会话签发短期 MCP 接入凭据的能力，并 SHALL 仅允许持有独立服务凭据
且来源在允许清单内的调用方使用；该服务凭据 MUST 与管理员接入 Token 及云端平台系统账号
配置相互独立，且 MUST NOT 具备调用任何业务工具的能力。

#### Scenario: 服务凭据不匹配
- **WHEN** 签发请求未携带或携带了不匹配的服务凭据
- **THEN** 系统必须拒绝签发

#### Scenario: 来源不在允许清单
- **WHEN** 签发请求的来源地址不在配置的允许清单内
- **THEN** 系统必须拒绝签发并记录该次尝试

#### Scenario: 请求超出时限或速率上限
- **WHEN** 签发请求要求的有效期超过上限，或同一调用方在单位时间内请求次数超过上限
- **THEN** 系统必须拒绝该请求

#### Scenario: 签发凭据的能力范围
- **WHEN** 通过该端点签发出凭据后
- **THEN** 该凭据必须只具备 MCP 接入能力，不得授予云端平台写权限
- **THEN** 服务凭据本身必须无法用于调用任何业务工具

### Requirement: 门禁决策必须可观测且不含明文凭据
系统 SHALL 为每一次拒绝记录被拦截的工具名、目标路径或参数摘要、拒绝原因与所属会话，并
SHALL 向前端交付一个可展示的拦截事件；相关记录 MUST 对凭据与口令脱敏。

#### Scenario: 拦截事件交付前端
- **WHEN** 一次工具调用被门禁拒绝
- **THEN** 前端必须收到一个可展示的拦截事件，使用户能看到被拒的动作与原因

#### Scenario: 审计记录中的凭据
- **WHEN** 被拦截的调用参数中包含 Token、口令或验证码
- **THEN** 落地的审计记录必须只保留脱敏摘要
